# 🚗 Car Rental System

A simple command-line based Car Rental System developed using Python.

## 📌 Project Description

This project is a Python CLI application that allows users to manage car rentals. 
Users can view available cars, rent cars, return cars, search for cars, and view rental records.

The project demonstrates Python programming fundamentals and Object-Oriented Programming (OOP).

## ✨ Features

- View all cars
- Rent a car
- Return a car
- Search for a car
- View rental records
- Customer name and phone number
- Rental days calculation
- Automatic total cost calculation
- Phone number validation
- Car availability status
- Object-Oriented Programming
- Error handling for invalid input
